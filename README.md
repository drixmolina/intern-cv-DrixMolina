# Intern CV - Drix Molina

A professional curriculum vitae (CV) webpage built with semantic HTML5.

## Overview

This project demonstrates the use of semantic HTML5 tags to create a well-structured CV page. The page includes:
- Professional header with name and job title
- Navigation menu
- About me section
- Education history
- Technical skills
- Experience/Projects section
- Footer with contact links

## Structure

The page uses semantic HTML5 tags including:
- `<header>` - For name and job title
- `<nav>` - For navigation links
- `<main>` - Main content container
- `<section>` - For distinct CV sections
- `<article>` - For specific entries
- `<footer>` - For copyright and social links

## Technologies Used

- HTML5 (semantic markup)
- Git & GitHub for version control

## How to View

Open `index.html` in your web browser to view the CV.
